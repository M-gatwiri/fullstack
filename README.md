# Fullstack Project

A modern fullstack application with separate frontend and backend components.

## Project Structure

```
fullstack/
├── frontend/          # Frontend application
└── backend/           # Backend application
```

## Getting Started

### Prerequisites

- Node.js (or your preferred runtime)
- npm, yarn, or pnpm (or your package manager)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/M-gatwiri/fullstack.git
cd fullstack
```

2. Install dependencies for both frontend and backend:

**Frontend:**
```bash
cd frontend
npm install
```

**Backend:**
```bash
cd backend
npm install
```

### Running the Application

**Frontend (Development):**
```bash
cd frontend
npm run dev
# or
npm start
```

**Backend (Development):**
```bash
cd backend
npm run dev
# or
npm start
```

## Development

### Frontend
Navigate to the `frontend/` directory for client-side application code and configuration.

### Backend
Navigate to the `backend/` directory for server-side application code and configuration.
